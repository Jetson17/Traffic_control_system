        How BFS Works
        1. BFS starts at the selected vertex.
        2. It uses a FIFO queue to process discovered vertices.
        3. It discovers neighboring vertices before processing the next level.
        4. It continues until all vertices reachable from the start have been explored.

        Time: O(V + E) with an adjacency list. Auxiliary space: O(V).

        BFS finds a minimum-edge path in an unweighted graph; it does not necessarily find the minimum-distance route when road weights differ.

        If the graph is disconnected, a traversal from one vertex visits only the vertices reachable from that start.
